# DockerCypressRun

A Dockerized Cypress test automation project that executes end-to-end tests on a scheduled cron job.

## Features

- Docker-based execution environment
- Automated Cypress E2E tests
- Cron job scheduling
- Easy deployment and reproducible test runs
- Suitable for CI/CD integration

## Technologies

- Docker
- Cypress
- Node.js
- Linux Cron
- Bash

## Purpose

This project demonstrates how to run Cypress tests inside a Docker container on a scheduled basis, making it useful for regression testing, health checks, and continuous quality assurance.
